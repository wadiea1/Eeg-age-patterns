# 🧠 EEG Age Patterns

Research project analyzing EEG signals from children and adolescents to detect brainwave patterns characteristic of different age groups.

## 🎯 About
This study applies **data normalization** and **pattern detection** methods to EEG data in order to understand how brain activity changes across developmental stages in children and adolescents.

## 🛠️ Methods & Tools
- Data normalization
- Pattern detection
- Jupyter Notebook / Python

Research project
